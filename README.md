# Hi, I'm wawaa 👋

I'm the creator of **METGUIDE**, a platform currently in development (launching in 2026-2027), created to guide anyone who wants to start a Metin2 project or improve an existing one.  
METGUIDE teaches **how to approach, plan, and execute** every aspect of server creation – from choosing the right server and planning your budget to implementing practical workflows that make development faster and more efficient.  
The platform provides **accurate guidance and best practices** for both beginners and those with some experience, helping users **learn to think and act**. 

I specialize in **Metin2 server development**, focusing on creating stable, optimized, and engaging server environments.
